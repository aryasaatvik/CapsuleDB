You will write a capsule the way a package author does, then compose it the way a host
application does, and run both against an in-memory database. Every block on this page is a region
of [`examples/quick-start.ts`](https://github.com/aryasaatvik/CapsuleDB/blob/main/examples/quick-start.ts),
which CI typechecks and runs against the built package.

## Prerequisites

- Bun 1.4.4 or newer. The example uses Bun SQLite; the same capsule runs on PostgreSQL, libSQL and
  Cloudflare D1 with a different [provider profile](/docs/providers).
- Effect 4.1.2 or newer.

## Install

```package-install
npm i capsuledb effect @effect/sql-sqlite-bun
```

## Declare the table

The package declares its table once. CapsuleDB renders the DDL for whichever dialect the host runs.
This capsule prefixes its table with the namespace CapsuleDB derives from its ID, so its tables are
easy to spot in a shared database.

The capsule's public surface is an Effect service. Its SQL and row shapes stay inside the package,

## Export the capsule

`Capsule.make` bundles the table, an append-only migration history and the service layer into one
module constant. It is pure, so a host can import it without running anything.

<Snippet file="examples/quick-start.ts" region="capsule" />

## Compose it in the host

The host lists the capsules it trusts and picks the provider profile that matches its client.
`Registry.layer` still requires the host's `SqlClient`; CapsuleDB never opens or closes it.

<Snippet file="examples/quick-start.ts" region="compose" />

## Run it

Building the layer prepares the registry first: it creates CapsuleDB's ledger and metadata tables,
applies the capsule's pending migration, and only then provides `Visits`.

<Snippet file="examples/quick-start.ts" region="run" />

`main` returns `2`, the second visit to `/docs`. The database now holds
`capsule_example_2e_visits` beside `capsuledb_registry_ledger` and `capsuledb_registry_metadata`.
Running it again against the same database reads the ledger once, finds it current, and applies
nothing.
