### Effect 4.1

**Breaking:** the `effect` peer range is now `>=4.1.0 <5`. Effect 4.0 is no longer supported.

Effect 4.1 removes the root `Crypto` service. Manifest and artifact checksums now use `Digest` from `effect/crypto`, with WebCrypto when the caller does not provide `Digest`. Checksum output is unchanged. Optional Effect SQL peer ranges stay `>=4.0.0 <5`, and the optional Alchemy peer range stays `>=2.0.0-beta.80 <3`.
